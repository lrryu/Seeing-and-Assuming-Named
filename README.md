# Source-attribution audit — interactive narrative

A single-file interactive page for the study *“A source-attribution audit of
vision-language models for urban land-use mapping from street view imagery”*
by Linyu Xiang, Haoran Tang, Junnan Chen, Shengyao Tan and Yiyang Yang.

Open `index.html` in a browser, or enable GitHub Pages
(Settings → Pages → Deploy from branch, root folder). No build step, asset
directory or server is required.

- One file, 0.88 MB; no external requests; works from `file://`.
- Figures 1–9 are native HTML/SVG views; the six condition samples are the only
  inline images.
- Bilingual: the `EN / 中文` switch in the header, or `?lang=zh` / `?lang=en`.
- Contact details are in the page footer.

Optional URL parameters: `?section=s01`–`s08`, `?static=1`, `?lang=zh|en`.
